# 🚀 Optimización de Conversión: Análisis A/B para Showz

Este repositorio contiene un análisis integral de experimentación A/B diseñado para optimizar el embudo de ventas de la plataforma **Showz**. El proyecto abarca desde la priorización estratégica de hipótesis hasta la validación estadística de resultados para la toma de decisiones basada en datos.

**Proyecto ID:** 10

## 🗺️ Hoja de Ruta Analítica (Roadmap)

El análisis se divide en 5 fases críticas para garantizar la robustez del veredicto:

1.  **Fase 01: Configuración y Auditoría:** Limpieza de datos y eliminación de usuarios presentes en ambos grupos (contaminación).
2.  **Fase 02: Priorización de Hipótesis:** Aplicación de frameworks **ICE** y **RICE** para identificar iniciativas de alto impacto.
3.  **Fase 03: Métricas Acumuladas:** Análisis de tendencias temporales en ingresos, conversión y ticket promedio (AOV).
4.  **Fase 04: Control de Anomalías:** Identificación de outliers (p99) y validación de significancia mediante el test **Mann-Whitney U**.
5.  **Fase 05: Conclusión y Directrices:** Emisión del veredicto final y plan de implementación.

## 📊 Hallazgos Principales

- **Impacto Estratégico:** La priorización RICE identificó que el formulario de suscripción masiva es la iniciativa con mayor potencial de ROI debido a su alcance.
- **Rendimiento:** El Grupo B demostró una **superioridad del 15.98%** en la tasa de conversión respecto al Grupo A.
- **Confianza:** Los resultados son estadísticamente significativos (P-value < 0.05), incluso tras remover el ruido de usuarios atípicos.

## 🏛️ Veredicto Final

> **ESTADO:** 🟢 **EXITOSO**
>
> **DECISIÓN:** Implementación inmediata de la variante B al 100% del tráfico. Se proyecta una mejora sostenible en la eficiencia de conversión y el crecimiento orgánico de la base de datos de usuarios.
